# NexApply Product Overview

NexApply is a two-sided job and internship portal connecting students with companies.

## User Roles

**Students**
- Browse and search job listings with skill-based matching
- Apply to positions with resume and cover letter
- Track application status through pipeline stages
- Upload and manage resume (PDF/DOCX/image or build from scratch)
- Save jobs for later review
- View personalized dashboard with match scores

**Companies (Recruiters)**
- Post and manage job listings (no approval required)
- Review applicants with resume viewer
- Move candidates through hiring pipeline stages
- Schedule and manage interviews
- Bulk actions on applications
- View dashboard with active listings and recent applicants

## Core Features

- **Authentication**: Login, register, Google OAuth, email verification, password reset
- **Job Listings**: Create, edit, delete, pause, close listings
- **Applications**: Submit applications, track status (Submitted → Under Review → Shortlisted → For Interview → Declined)
- **Resume Management**: Upload PDF/DOCX/image or build resume from scratch, profile strength tracker
- **Resume Matching**: PostgreSQL full-text search ranks listings against student resume (no AI)
- **Search & Filter**: Filter by keyword, job type, location, work setup
- **Notifications**: Real-time updates on application status changes
- **Messaging**: Communication between students and recruiters (placeholder)

## Job Types

FullTime, PartTime, Internship, Freelance, Remote

## Work Setup

OnSite, Remote, Hybrid
